# Project preferences

## Git workflow
- The user wants every phase of work committed and pushed to `origin/main` as it completes — don't batch multiple phases into one commit/push at the end. After finishing a discrete chunk of work (a feature, a fix, a meaningful set of related edits), commit it and push immediately rather than waiting to be asked.
- Still follow standard git safety practices: review `git status`/`git diff` before staging, use descriptive commit messages, never force-push or skip hooks unless explicitly asked.
